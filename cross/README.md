# Cross-domain drills

Drills that combine concepts from several domains, listed in the concept inventory's Cross-domain section. They use the same folder shape and frontmatter as `/drills`, list every concept they touch in `concepts`, and count toward coverage in each domain.

All 15 inventory drills are in `cross/4/`. Each has an editable starter, a live scene or measurement, a behavior check, and a reference answer in `solutions/cross/4/`.
