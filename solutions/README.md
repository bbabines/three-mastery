# Solutions

Never open this folder during a drill.

It holds reference solutions for code drills, which start in Loop 2, and it mirrors the repo. The reference for `drills/2/<domain>/<concept>/<drill>/drill.ts` lives at `solutions/drills/2/<domain>/<concept>/<drill>/drill.ts`. `npm run verify` runs every acceptance test against these files to prove they pass.

Loop 1 pages are read-the-code quizzes graded on the page, so they have no solutions here.
