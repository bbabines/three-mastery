## Definition

A pro jewelry file keeps its gems small, flat-faceted, and closed, spends its triangles on the metal's curves, and tags each part so the viewer knows which material to use.

## Cost lens

Gems are about 5% of the triangles drawn. A shape that's reused, like a stone or a bead, costs download only once when the file shares it.
